Пульт судьбы — исходный проект Fabric для Minecraft 1.20.1

Для сборки нужен JDK 17 и Gradle (8.x):
1) Распакуйте архив.
2) В папке проекта выполните: gradle build
3) Готовый .jar (без -sources) появится в build/libs.

Установка: положите .jar в папку mods вместе с Fabric API 0.92.x для 1.20.1.
Управление: команда /pult выдаёт пульт. ПКМ пультом подсказывает команды
/pult_blue (появляется преследователь) и /pult_red (пока только сообщение).
